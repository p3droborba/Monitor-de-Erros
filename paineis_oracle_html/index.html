Painéis Oracle

Estrutura HTML consolidada para visão geral, análise operacional e BI gerencial.

Pronto para adaptação

Painel 1 — Visão geral Oracle

Mostra a saúde da coleta, volume de sessões, sessões ativas, sessões bloqueadas e sinais gerais de risco operacional.

Base principal: fact_oracle_summary.csv e fact_collection_runs.csv

Painel 2 — Análise operacional de sessões

Mostra cada sessão em nível de linha, com foco em atividade, bloqueio, origem, programa, módulo e sinais úteis para investigação.

Base principal: fact_oracle_sessions.csv

Painel 3 — BI gerencial de operação Oracle

Transforma os sinais técnicos em leitura gerencial: estabilidade, tendência, concentração e pontos de atenção.

Base principal: resumo + sessões detalhadas

Como usar

Este pacote entrega a parte HTML da solução. Ele já organiza os painéis com nomes em linguagem natural e separa a navegação por finalidade. O próximo passo é ligar os componentes aos CSVs gerados pelo coletor ou transformar essa estrutura em Power BI, Streamlit ou aplicação web local.

Arquivos incluídos: index.html, 3 páginas HTML de painel, styles.css, app.js e README.html.md
