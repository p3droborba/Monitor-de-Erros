O ambiente opera com estabilidade na maior parte do período, mas há concentração de sessões em origem JDBC e aumento de bloqueios em horários específicos. O risco operacional cresce quando o volume de sessões ativas sobe junto com sessões bloqueadas e sessões longas.

Recomendação de navegação

Use este painel para perceber tendência. Quando houver desvio, desça para o Painel 1 para ver a coleta afetada e então para o Painel 2 para identificar a sessão responsável.
